An archive of LilyPond sheet music files, and a set of scripts for working with them

- `process-lilypond.sh` creates a PDF and MIDI file from each file in `source-files`
- `make-songbook.sh` combines those LilyPond files into a single 'songbook', in alphabetical order
- `reprocess-songbook.sh` exists so that you can manually edit the LilyPond file
  generated by `make-songbook.sh` (e.g. to add `\pageBreak` commands or
  re-order the songs) and then generate a new songbook from it using the same
  style file and other defaults used in the other scripts.
    - if you make extensive modifications you may want to give this new songbook another name and
      place it in the `source-files` directory so that it doesn't get overwritten if you re-run
      `make-songbook.sh`
